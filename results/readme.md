# RAMFP — World Model and Ranker Evaluation

**Date:** October 2026
**Corpus:** StatsBomb Open Data (2,651 matches, 2,133 formation-change decisions)

## Repository Structure

| Folder | Contents |
|---|---|
| `world_model/` | Core world model architecture, training scripts, and adapters |
| `model_1/` | Ranker model, opponent model, and associated evaluation scripts |

| `results/` | Final evaluation JSONs, CSVs, and summary statistics |
